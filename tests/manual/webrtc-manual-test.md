# WebRTC 视频通话功能 - 手动验证清单

## 前置条件
1. ✅ Pusher 环境变量已配置（NEXT_PUBLIC_PUSHER_KEY, NEXT_PUBLIC_PUSHER_CLUSTER, PUSHER_SECRET）
2. ✅ 部署已完成（https://app.lokfeel.com）
3. ✅ 有两个测试账号（账号 A 和 账号 B）

---

## 测试步骤

### 1. 基础功能测试

#### 1.1 视频按钮显示
- [ ] 登录账号 A
- [ ] 进入 `/dashboard/chats`
- [ ] 选择一个聊天会话
- [ ] **验证**：右上角显示视频按钮（摄像头图标）

#### 1.2 发起视频通话
- [ ] 点击视频按钮
- [ ] **验证**：弹出 `VideoCallModal` 组件
- [ ] **验证**：显示本地视频预览
- [ ] **验证**：显示"正在呼叫..."状态

#### 1.3 接收视频通话邀请
- [ ] 使用账号 B 登录（另一个浏览器或隐私窗口）
- [ ] 账号 A 向账号 B 发起视频通话
- [ ] **验证**：账号 B 收到 `IncomingCallModal` 弹窗
- [ ] **验证**：显示来电者信息（头像、名字）

#### 1.4 接听视频通话
- [ ] 在账号 B 点击"接听"按钮
- [ ] **验证**：两个账号都进入视频通话界面
- [ ] **验证**：显示远程视频（对方的摄像头画面）
- [ ] **验证**：显示本地视频（自己的摄像头画面）

#### 1.5 挂断视频通话
- [ ] 点击"挂断"按钮
- [ ] **验证**：视频通话界面关闭
- [ ] **验证**：返回聊天界面

#### 1.6 拒绝视频通话
- [ ] 账号 A 向账号 B 发起视频通话
- [ ] 在账号 B 点击"拒绝"按钮
- [ ] **验证**：账号 A 显示"对方已拒绝"提示

---

### 2. 控制功能测试

#### 2.1 音频开关
- [ ] 在视频通话中，点击"麦克风"按钮
- [ ] **验证**：按钮状态切换（静音/取消静音）
- [ ] **验证**：对方听不到声音（静音状态）

#### 2.2 视频开关
- [ ] 在视频通话中，点击"摄像头"按钮
- [ ] **验证**：按钮状态切换（关闭/打开摄像头）
- [ ] **验证**：对方看不到画面（关闭状态）

#### 2.3 切换摄像头（移动端）
- [ ] 在移动端，点击"切换摄像头"按钮
- [ ] **验证**：摄像头从前置切换到后置（或反之）

---

### 3. 边界情况测试

#### 3.1 超时未接听
- [ ] 账号 A 向账号 B 发起视频通话
- [ ] 等待 30 秒（不接听）
- [ ] **验证**：账号 A 显示"对方未接听"提示
- [ ] **验证**：视频通话界面自动关闭

#### 3.2 对方离线
- [ ] 账号 B 离线（关闭浏览器）
- [ ] 账号 A 向账号 B 发起视频通话
- [ ] **验证**：账号 A 显示"对方离线"提示

#### 3.3 已在其他聊天中
- [ ] 账号 A 正在与账号 B 视频通话
- [ ] 账号 C 向账号 A 发起视频通话
- [ ] **验证**：账号 A 显示"忙碌中"提示

---

### 4. 性能测试

#### 4.1 连接速度
- [ ] 发起视频通话 → 接听
- [ ] **验证**：连接建立时间 < 5 秒

#### 4.2 视频质量
- [ ] 在视频通话中
- [ ] **验证**：视频画面流畅（≥ 24 FPS）
- [ ] **验证**：延迟 < 500ms

#### 4.3 音频质量
- [ ] 在视频通话中
- [ ] **验证**：音频清晰，无杂音
