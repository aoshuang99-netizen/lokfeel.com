Step 1: 创建 Neon PostgreSQL 数据库
免费额度足够 MVP，支持 Serverless，无需管理连接池
注册 Neon 账号
访问 console.neon.tech/signup，使用 GitHub 或 Google 账号注册。
创建 Project
  • 点击 Create Project
  • Project name: nexus-production
  • Region: 选择 AWS US East (Virginia)（Vercel 默认区域，延迟最低）
  • Branch name: main（默认即可）
获取连接字符串
创建完成后，在 Dashboard 的 Connection Details 中找到连接字符串。选择 Pooled connection（推荐用于 Serverless）：
postgresql://nexus_owner:xxxxxxxx@ep-cool-name-123456.us-east-2.aws.neon.tech/nexus_production?sslmode=require&pgbouncer=true
⚠️ 请复制完整的连接字符串并安全保存，后续步骤会用到。Pooled connection 带 pgbouncer=true 参数，对 Serverless 环境更友好。
⚙️
Step 2: 配置 Vercel 环境变量
将数据库连接字符串和认证密钥注入生产环境
设置 DATABASE_URL
在终端执行（替换为你的实际连接字符串）：
cd nexus-app export PATH="$HOME/.npm-global/bin:$PATH" # 设置数据库连接字符串（Production 环境） vercel env add DATABASE_URL production # 粘贴上一步获取的 Neon 连接字符串（带 pgbouncer=true） # 生成 AUTH_SECRET（用于 NextAuth JWT 加密） openssl rand -base64 32 # 复制生成的随机字符串 vercel env add AUTH_SECRET production # 粘贴上面生成的随机字符串
更新 NEXTAUTH_URL 和其他变量
如果使用了自定义域名（Step 4），需要更新：
# 设置应用 URL（使用自定义域名后更新） vercel env add NEXTAUTH_URL production # 值: https://your-nexus-domain.com vercel env add AUTH_URL production # 值: https://your-nexus-domain.com vercel env add NEXT_PUBLIC_APP_URL production # 值: https://your-nexus-domain.com
（可选）配置 OAuth Providers
如果需要 Google/GitHub 登录：
# Google OAuth # 1. 去 https://console.cloud.google.com/apis/credentials 创建 OAuth 2.0 Client ID # 2. Authorized redirect URIs: https://your-domain.com/api/auth/callback/google vercel env add GOOGLE_CLIENT_ID production vercel env add GOOGLE_CLIENT_SECRET production # GitHub OAuth # 1. 去 https://github.com/settings/developers 创建 OAuth App # 2. Authorization callback URL: https://your-domain.com/api/auth/callback/github vercel env add GITHUB_CLIENT_ID production vercel env add GITHUB_CLIENT_SECRET production
💡 当前已配置的环境变量：AUTH_SECRET, NEXTAUTH_URL, AUTH_URL, NEXT_PUBLIC_APP_URL, NEXT_PUBLIC_APP_NAME。
需要新增：DATABASE_URL（必须）、GOOGLE_CLIENT_ID/SECRET（可选）。

Step 3: 初始化数据库 + 创建管理员
推送 Schema 到 Neon + 创建超级管理员账号
推送 Prisma Schema 到数据库
在本地终端执行（需要设置 DATABASE_URL 环境变量）：
cd nexus-app # 方法1: 直接使用 db-init.sh 脚本（推荐） # 先创建 .env 文件 echo 'DATABASE_URL="postgresql://nexus_owner:xxx@ep-xxx.neon.tech/nexus_production?sslmode=require&pgbouncer=true"' > .env # 运行一键初始化脚本 bash scripts/db-init.sh
# 方法2: 手动逐步执行 # 生成 Prisma Client npx prisma generate # 推送 Schema 到数据库（创建所有表） npx prisma db push # 创建管理员账号 + 系统配置 # 默认密码: Nexus@Admin2026! (请立即修改!) ADMIN_EMAIL="your-email@example.com" npx tsx prisma/init-admin.ts # 可选: 导入演示数据 npx tsx prisma/seed.ts
⚠️ 管理员默认密码为 Nexus@Admin2026!，首次登录后请立即通过 Admin 后台修改密码。
可通过环境变量自定义：ADMIN_EMAIL=xxx ADMIN_PASSWORD=xxx npx tsx prisma/init-admin.ts
验证数据库连接
确认数据已正确写入：
# 方法1: 访问 Vercel 健康检查 curl https://nexus-app-chi.vercel.app/api/health # 方法2: 使用 Prisma Studio 查看数据 DATABASE_URL="你的连接字符串" npx prisma studio # 浏览器打开 http://localhost:5555 查看 User 和 SystemConfig 表

Step 4: 腾讯云域名 DNS 解析
将域名指向 Vercel，启用 HTTPS
登录腾讯云 DNS 控制台
访问 console.cloud.tencent.com/cns，找到你的域名。
在 Vercel 添加自定义域名
  • 访问 Vercel 项目 Settings → Domains
  • 添加主域名：your-domain.com
  • 添加 www 子域名：www.your-domain.com
配置 DNS 解析记录
Vercel 会告诉你需要添加的 DNS 记录。根据域名是否已经在 Vercel 上，有两种配置方式：

在腾讯云 DNS 添加以下记录（推荐用于根域名）：

类型主机记录记录值TTL
A@76.76.21.21600
CNAMEwwwcname.vercel-dns.com600

如果 Vercel 提示使用 CNAME 验证：

类型主机记录记录值TTL
CNAMEyour-domain.comcname.vercel-dns.com600
TXT_vercel.your-domain.comvercel-domain-verification=xxx600
💡 Vercel 的 IP 地址：76.76.21.21（这是 Vercel 负载均衡器，不是真实服务器）。
如果你使用腾讯云 CDN 或其他代理，也可以用 CNAME 指向 cname.vercel-dns.com。
等待 DNS 生效 + SSL 证书签发
  • DNS 传播: 通常 1-5 分钟（全球最多 48 小时）
  • SSL 证书: Vercel 自动签发 Let's Encrypt，通常 1-2 分钟
  • 在 Vercel Domains 页面查看状态，出现 Valid 表示成功
更新环境变量指向新域名
DNS 生效后，更新 Vercel 环境变量：
vercel env rm NEXTAUTH_URL production vercel env add NEXTAUTH_URL production # 值: https://your-domain.com vercel env rm AUTH_URL production vercel env add AUTH_URL production # 值: https://your-domain.com vercel env rm NEXT_PUBLIC_APP_URL production vercel env add NEXT_PUBLIC_APP_URL production # 值: https://your-domain.com # 重新部署以使环境变量生效 vercel --prod

Step 5: Admin 后台使用指南
数据监控、用户管理、系统配置
页面URL功能权限
Admin Dashboard/admin总览面板：用户数、匹配数、收入等核心指标ADMIN+
用户管理/admin/users查看/搜索/禁用用户、角色管理ADMIN+
匹配管理/admin/matches查看所有匹配、手动创建/取消匹配ADMIN+
数据分析/admin/analytics用户增长、匹配成功率、留存率图表SUPER_ADMIN
系统配置/admin/settings匹配参数、定价、维护模式等SUPER_ADMIN
🔐 权限控制说明：
middleware.ts 已配置路由保护 — /admin/* 只允许 ADMIN 和 SUPER_ADMIN 角色访问。
/dashboard/* 需要登录（任意角色）。未登录用户自动跳转到 /login。
⚠️ 安全建议：首次登录管理员账号后，请立即修改默认密码。建议通过 OAuth (Google/GitHub) 登录管理员账号，避免密码泄露风险。
