# RISK_AND_DECISIONS · 风险与待批事项

> 两类东西放在一起，因为它们总是成对出现：**每个未决决策都养着一批风险。**
>
> 决策状态：`已决` / `待批` / `已否决`
> 风险状态：`OPEN` / `MITIGATING` / `CLOSED`（关闭必须写清除证据）
>
> 规则：**工程不替产品做产品决策。** 遇到产品/法律/资金事项，登记 + 给出选项与后果，
> 不擅自选一个继续跑。
