## 🔴 P0 严重问题 - 功能完全不可用

### 1. Activity页面使用Mock数据
**位置**: `app/dashboard/activity/page.tsx` 第70-112行
**问题**: 活动数据是硬编码的setTimeout模拟数据，不是真实API
```typescript
// 模拟数据
setTimeout(() => {
  setActivities([...]) // 硬编码数据
}, 1000);
```
**影响**: 用户看不到真实的活动记录
**修复**: 接入 `/api/activity` 真实API

### 2. 请求处理API端点不存在
**位置**: `app/dashboard/activity/page.tsx` 第122行
**问题**: 调用 `/api/requests/${activityId}` 但API端点未实现
**影响**: 女性用户无法接受/拒绝请求
**修复**: 创建 `/api/requests/[id]/route.ts`

### 3. 匹配后没有引导
**位置**: `app/dashboard/discover/page.tsx` 第109-113行
**问题**: Like后只显示toast，没有检查是否匹配成功
**影响**: 用户不知道是否匹配成功，无法进入聊天
**修复**: API返回匹配状态，前端引导到聊天
