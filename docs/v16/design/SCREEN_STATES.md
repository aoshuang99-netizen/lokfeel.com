# 屏幕状态规范（SCREEN STATES）

> 原则只有一条：**四态都是真实状态，不是样式**。
> 空态不能说成"加载中"，错误不能吞成空态，未接线不能说成"暂无数据"。

## 一、通用四态

| 状态 | 触发条件 | 呈现 | 可用操作 |
|---|---|---|---|
| **Loading** | 请求在途且无缓存 | `role="status"` + `aria-live="polite"` + 旋转图标 + 「正在读取…」 | 无（不显示假占位数字） |
| **Empty** | 服务端 200 且集合为空 | 虚线框 + 一句说明（含"这是真实结果"） | 视屏而定（如「开始输入目标」） |
| **Error** | 请求失败 / 非 2xx / 契约不符 | `role="alert"` + 服务端原因原文 | 重试（由所在屏提供） |
| **Ready** | 有数据 | 正常渲染 | 按服务端下发的能力决定 |

> 实现：`living-workspace.tsx` 的 `Loadable` 组件；租户域端点另有三段"来源可读性"判定
> （`tenantSource`：`null` = 仍在读，不产节点也不产说明，避免说明抖动）。

## 二、逐屏状态

### Now

| 状态 | 表现 |
|---|---|
| Loading | 两张计数卡显示「—」，列表「正在读取…」 |
| Empty | 「没有待处理事项。这是真实结果 —— 本页不会为了填满而生成内容。」 |
| Error | 红色条 + `读取失败：<原因>` |
| Ready | 未读数 + 最近 6 条；第三张卡「待你介绍」来自提案端点 |

### Studio

| 状态 | 表现 |
|---|---|
| 未编译 | 空态：「还没有工作区。先写下一个目标。」+ **「开始输入目标」按钮**（聚焦底部输入框） |
| 编译失败 | 红色块 + 原因 + 当前支持的目标类型列表（不编造建议） |
| 编译成功 | 画布 + 缺失项清单（`missionDraft.missing`），并明说"不会替你编默认对价或判据" |
| 创建中 | 按钮进入 pending；不伪造进度条 |
| 创建成功 | 只认服务端返回的 `mission.id`；幂等重放单独提示 |
| 创建失败 | 服务端原因原文 |

### Field

| 状态 | 表现 |
|---|---|
| Loading | 图区骨架（不画假节点） |
| Empty | 「还没有可展示的连接」+ 指向 Studio |
| Error | 图区替换为错误块（不保留旧图，避免"看起来还有数据"） |
| 图渲染不可用 | `field-fallback.tsx` 的 2D 列表降级 |

### Consent

| 状态 | 表现 |
|---|---|
| Loading | 列表骨架 + Inspector 显示「选择一条提案」 |
| Empty | 「没有待表态的提案」 |
| Error | 错误块；Inspector 同步显示失败原因 |
| Ready | 每行显示双方表态 + 服务端下发的可执行动作；`canIntroduce=false` 时不可点 |
| 动作结果 | 只显示服务端返回的 `action`，不做乐观更新 |

### Outcomes

| 状态 | 表现 |
|---|---|
| Loading | 时间轴骨架 |
| Empty | 「还没有记录成果」 |
| Error | 错误块 |
| Ready | 每条带核验级别、`canConfirm` / `canVerify`；未核验数取服务端 `counts.unverified` |

### Agents

| 状态 | 表现 |
|---|---|
| Loading | 运行列表骨架 |
| Empty | 「这个筛选下没有运行」+ 回显服务端过滤条件（说明"这不是全量"） |
| Error | 错误块 |
| Ready | 状态 + 风险 + 成本 + `execution.available` 与其原因原样展示 |
| 审批 | approve / reject 以服务端返回为准 |

### Console 七屏

每屏同一套四态；额外一条：**无权限**渲染为不可点的 `<span>` + 「无权限」，
不是死链、也不是"点进去才 403"。

## 三、阶段条的四态（新增）

| 状态 | 条件 | 显示 |
|---|---|---|
| 未就绪 | 端点未返回 | `—` + 「未就绪」+ tooltip「该端点尚未返回，因此不显示数字」 |
| 无待办 | 端点返回且计数为 0 | `0` + 「无待办」 |
| 待处理 | 计数 > 0 且非焦点 | `N` + 「待处理」 |
| 当前 | 焦点段 | `N` + 「在等你」（仅当该段确实有待办） |

## 四、动效与降级

| 场景 | 行为 |
|---|---|
| `prefers-reduced-motion: reduce` | `--lf-dur-fast/dur/dur-slow` 全部 0ms；画布不旋转、不视差 |
| 图渲染失败 | 保留 2D 列表，功能不丢 |
| 移动端 | Inspector 变底部浮层（80dvh 上限，可滚动），composer 与浮层均含安全区 |
