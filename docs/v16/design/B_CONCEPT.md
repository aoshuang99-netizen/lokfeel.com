# 方案 B · Living Paper（纸面）

> 状态：**原型**。未进入生产。可交互预览：`design/preview/B-living-paper.html`
> 评分：综合 **4.03**（详见 `COMPARISON_SCORECARD.md`）

## 一、方向

暖白数字纸张 + 编辑式排版。关系网络退到背景，成为低噪声的关系画布；主体是**可读的文本**：
谁提出了什么、依据是什么、谁在等谁表态。适合长时间阅读与审批。

## 二、原型里真实做了的部分

| 要素 | 做法 |
|---|---|
| 版式 | 单栏 720px 阅读宽度 + 右侧窄栏（证据），字号与行高按长文可读性设定 |
| 关系 | 顶部一条低对比度关系带，只标"我在链条的哪一段"，不做动画 |
| 审批 | 每张卡片的三个按钮（同意 / 拒绝 / 撤销）都在首屏可见，附不可逆操作的说明 |
| 状态 | 空态给"下一步该做什么"的一句指引，而不是空白 |
| 打印 | 支持打印为 A4（审批留档场景真实存在） |

## 三、为什么不做成生产

1. **与现有产品结构冲突**：`/workspace` 的六屏本质是"图 + 审查器"，纯纸面会让 Field 屏失去意义；
2. **品牌辨识度弱**：与 Notion / Linear 一类纸面工具难以区分，而 LokFeel 的差异点是"意图编译"；
3. **密度上限**：720px 单栏在 1440px 屏幕上浪费 50% 宽度，运维视角一次能看的信息太少。

## 四、值得吸收的部分（已吸收进方案 C）

- **Inspector 的纸面调色板**：双世界的右半直接用 B 的暖白 + 墨黑 + 暖金；
- 审批按钮的"不可逆操作必须写清后果" → Consent 屏沿用；
- 打印友好的排版 → 记入后续待办（当前未实现）。
