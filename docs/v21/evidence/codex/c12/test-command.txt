## 环境备注（本地沙箱）

- `env -u NODE_OPTIONS` 是必需的：注入的 shim 会让 eslint / Next 构建输出 EPIPE。
- 本地 curl 必须 `--noproxy '*'`：系统代理会劫持 127.0.0.1。
- 本机无 Playwright 下载版 Chromium 时用 `PW_CHANNEL=chrome`（借用系统 Chrome）。
