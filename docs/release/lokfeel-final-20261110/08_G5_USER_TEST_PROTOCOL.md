## 1. 验收标准（先行确定，不按结果反推）

- **人数**：≥5 名符合目标画像的测试者（画像见 §2）。
- **通过线**：**4/5 两人**在无人工提示下，30 分钟内完成任务清单（§4）且问卷两道关键题均答对：
  - Q1「这个平台是做什么的？适合你吗？」——能用自己的话说出"AI 协作/连接编排"核心（而不是"交友网站/AI 聊天机器人"）。
  - Q2「订阅后你能得到什么？怎么验证结果是真的？」——能指出权益边界与**三级核验**中至少两级（对手方确认/外部核验）。
- **通过即 G5 = PASS（4/5 达标）**；任何一位在付费页把价格或权益理解错 ⇒ 记缺陷回修，G5 保持未过。

## 2. 目标用户画像（招募筛选）

1. 需要跨方协作完成目标的人：商务拓展 / 招募 / 投融资对接 / 合作负责人 / 独立顾问。
2. 有真实"找人/找合作方"的任务在手（测试用他们自己的真实任务）。
3. 未接触过本产品（排除已看过文案的内部人员）。
4. 设备真实：自己的手机或笔记本，正常网络，不装任何测试插件。

## 3. 招募文案（可直接发）

> **寻找 5 位体验官（30 分钟，¥xx 致谢/无报酬，由你定）**
> 我们在做 LokFeel——一个把"我想认识/联系某人做某事"变成 AI 可执行任务的协作平台，正在找 5 位有真实"找合作方"任务的人体验从注册到出结果的全程，并回答 8 个问题。30 分钟，全程录屏 + 4 道问卷，你的吐槽直接进产品。报名：回复本条 + 一句话描述你最近想联系谁做什么。

## 4. 测试脚本（主持人照读；全程录屏，观察不打断）

**开场（2 分钟）**：「请用你自己的方式打开 lokfeel.com，说出你在想什么。」——观察首屏 10 秒内能否说出这是什么（G1 八问 Q1）。
**任务 T1（5 分钟）**：不提示地找到"这是给谁用的、怎么用"的答案（观察是否走到 /product 或 /how-it-works）。
**任务 T2（10 分钟）**：注册 → 用**你自己真实的协作意图**创建第一个任务 → 走到同意门禁一步（观察 Consent 界面是否能看懂授权什么、给谁看）。
**任务 T3（5 分钟）**：找到"订阅要付多少钱、各档差在哪、试用期怎么算"（观察 /pricing 理解）。
**任务 T4（5 分钟）**：「如果 AI 给你交付了一个结果，你怎么知道它是真的？」（观察是否发现三级核验/成果页）。
**收尾问卷（3 分钟）**：§5 问卷 + SUS 十题（可选）。

**记录表**：每任务记「无提示完成 / 提示后完成 / 未完成」+ 停留点 + 原话吐槽。

## 5. 验收问卷（8 问，对齐 G1 八问）

1. 用一句话说说这个网站是做什么的？（关键题 Q1）
2. 它适合你现在的场景吗？为什么？
3. 你会怎么开始用？（说出入口路径）
4. 注册时你犹豫了吗？因为什么？
5. AI 替你做事时，你觉得"授权/同意"控制了什么？
6. 三档订阅你选哪档？为什么？（记录价格记忆是否准确：$49/$149/$399）
7. 平台怎么证明 AI 交付的结果是真的？（关键题 Q2）
8. 最大的一个槽点是什么？
